# Feature Graphic Generation Prompt

## Specifications
- Dimensions: 1024 x 500 pixels
- Format: PNG or JPEG
- Purpose: Google Play Store feature graphic

## Design Prompt

Create a modern, sleek feature graphic for "Loudify" - a text-to-speech reading app.

**Visual Elements:**
- Dark gradient background (#0f0f1a to #1a1a2e)
- Place the Loudify app icon prominently on the left side
- Show a stylized phone mockup displaying text being read with a highlighted sentence
- Include subtle sound wave or audio visualization elements
- Add floating UI elements: play button, speed controls, voice selector icons
- Use accent color: vibrant pink/red (#e94560)

**Typography:**
- App name "Loudify" in bold, modern sans-serif font
- Tagline below: "Turn Text Into Speech" or "Read Aloud, Anywhere"
- Text color: light (#f0f0f5)

**Style:**
- Modern, minimalist design
- Dark theme aesthetic
- Professional but approachable
- Focus on readability and clarity
- Subtle depth with shadows and gradients

**Mood:**
- Innovative, accessible, user-friendly
- Tech-forward but not intimidating
- Emphasize the "listening" experience

A 1024x500 Google Play feature graphic for Loudify text-to-speech app. Dark gradient background (#0f0f1a to #1a1a2e), app icon on left, phone mockup showing highlighted text in center, sound waves, pink accent color (#e94560), "Loudify - Read Aloud" text, modern minimalist style.
